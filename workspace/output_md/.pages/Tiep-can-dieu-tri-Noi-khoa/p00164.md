Bảng 9.7. Các phác đồ tiệt trừ H. pylori

| Phác đồ 3 thuốc* | PPI + A + C |
| :--- | :--- |
| | PPI + A + M |
| | PPI + C + M |
| | PPI + A + L |
| **Phác đồ 4 thuốc** | PPI + T + M (Ti) + B** |
| | PPI + A + C + M (Ti) |
| | PPI + A + L + B |
| **Phác đồ nối tiếp** | PPI + A |
| | Tiếp theo sau đó PPI + C + M (Ti) |
| **Phác đồ lai ghép** | PPI + A |
| | Tiếp theo sau đó PPI + A + C + M (Ti) |
| **Phác đồ 2 thuốc liều cao*** | PPI + A |

* Phác đồ 3 thuốc hiện tại kém hiệu quả thường không sử dụng nếu không có kháng sinh đồ điều trị. ** Phác đồ hiện tại cho hiệu quả thành công cao nhất khi người bệnh chưa từng điều trị. *** PPI và Amoxicilline được dùng với liều cao hơn so với liều thông thường ở Bảng 9.2.
