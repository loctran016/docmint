5.2. Vi thể

5.2.1. Loại mô học

Ung thư biểu mô tuyến là loại mô học thường gặp nhất của UTĐT (bảng 1).

Bảng 1. Phân loại mô học UTĐT theo Tổ Chức Y Tế Thế Giới (WHO)

| Loại mô học | Tỷ lệ |
| :--- | :--- |
| Carcinôm tuyến | 90-95% |
| Carcinôm tuyến nhầy | 10% |
| Carcinôm tế bào nhẫn | < 1% |
| Carcinôm tế bào vẩy | |
| Carcinôm vẩy tuyến | |
| Carcinôm tủy | |
| Carcinôm không biệt hóa | |

Những loại khác rất hiếm gặp không được đề cập trong bảng phân loại trên gồm carcinôm tế bào nhỏ, carcinôm tế bào khổng lồ, lymphoma ác tính, carcinosarcoma...

5.2.2. Độ biệt hóa mô

Độ biệt hóa của ung thư liên quan đến tiên lượng cũng như lựa chọn điều trị. Hệ thống phân loại của Hiệp hội Quốc tế Phòng Chống Ung thư (UICC) chia thành 4 độ như sau:

- G1: biệt hóa tốt
