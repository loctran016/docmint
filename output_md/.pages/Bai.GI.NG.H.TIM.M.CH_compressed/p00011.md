# SƠ ĐỒ KHÁI NIỆM

**Sơ đồ: Sơ đồ khái niệm**
- Phôi thai học --> [Hình: Biểu tượng trái tim]
- Bơm máu
- Điện học
- Động mạch vành
- [Hình: Biểu tượng trái tim] --> Hệ động mạch (Hậu tải)
  - Sức cản ngoại biên
  - Huyết áp
  - Tưới máu mô
- [Hình: Biểu tượng trái tim] --> Hệ tĩnh mạch (Tiền tải)
- Hệ động mạch (Hậu tải) --> Hệ mao mạch
- Hệ tĩnh mạch (Tiền tải) --> [Hình: Biểu tượng trái tim]
- Hệ mao mạch --> Hệ bạch huyết Vận chuyển và tái hấp thu dưỡng chất
- Hệ bạch huyết Vận chuyển và tái hấp thu dưỡng chất --> Hệ tĩnh mạch (Tiền tải)
- Điều hòa
  - Cơ chế tại chỗ
  - Hệ thần kinh
  - Nội tiết tố
  - Điều hòa --> Hệ tĩnh mạch (Tiền tải) (đường đứt nét)
  - Điều hòa -.-> [Hình: Biểu tượng trái tim] (đường đứt nét)
  - Điều hòa --> Hệ động mạch (Hậu tải) (đường đứt nét)
