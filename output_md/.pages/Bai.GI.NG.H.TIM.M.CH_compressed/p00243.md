**Bảng 16.4. Tiêu chuẩn điện tâm đồ trong nhồi máu cơ tim (ACC/AHA 2013)**

| Trường hợp không có block nhánh trái | |
| :--- | :--- |
| **ST chênh lên**: ST chênh lên mới ở hai chuyển đạo liên tiếp với: | |
| - ST chênh lên ≥ 0,1 mV ở mọi chuyển đạo, trừ V2, V3 | |
| - ST chênh lên ≥ 0,2 mV ở V2, V3 đối với nam ≥ 40 tuổi | |
| - ST chênh lên ≥ 0,25 mV ở V2, V3 đối với nam < 40 tuổi | |
| - ST chênh lên ≥ 0,15 mV ở V2, V3 đối với nữ | |
| **ST chênh xuống và thay đổi sóng T**: | |
| - ST chênh xuống đi ngang/đi xuống ≥ 0,5 mV mới ở hai chuyển đạo liên tiếp | |
| - Sóng T đảo ≥ 0,1 mV ở hai chuyển đạo liên tiếp với sóng R cao ưu thế hoặc tỉ số R/S > 1 | |
| **Trường hợp có block nhánh trái** | |
| ST chênh lên ≥ 1 mm và cùng chiều với phức bộ QRS | 5 điểm |
| ST chênh xuống ≥ 1 mm ở V1, V2 hay V3 | 3 điểm |
| ST chênh lên ≥ 5 mm và trái chiều với phức bộ QRS | 1 điểm |
| Tổng điểm ≥ 3: độ đặc hiệu chẩn đoán nhồi máu cơ tim cấp lên đến 98% | |
| **Trường hợp có nhồi máu cơ tim cũ (không có phì đại thất trái và block nhánh trái)** | |
| - Bất kì sóng Q ≥ 0,02 giây ở V2 – V3 hoặc QS ở V2 – V3 | |
| - Sóng Q ≥ 0,03 giây và ≥ 0,1 mV hoặc QS ở DI, DII, aVL, aVF hoặc V4 – V6 với hai chuyển đạo liên tiếp | |
| - Sóng R ≥ 0,04 giây ở V1 – V2 và R/S ≥ 1 với sóng T dương cùng chiều trong trường hợp không có rối loạn dẫn truyền | |

Trong nhồi máu cơ tim cấp ST chênh lên, chúng ta có thể dựa vào hình ảnh điện tâm đồ để xác định vùng nhồi máu cơ tim. Ở đây, chúng tôi trình bày cách phân vùng theo Braunwald 2019.

- V1, V3: trước vách hay mỏm
- V4, V6: mỏm hay thành bên
- DI, aVL: trước bên
- V1 – V6: vùng trước rộng
